# DelayedPinkCandy

### Does pink candy feel boring? Want it to be more "surprising"? This is the plugin for you!
[![Github All Releases](https://img.shields.io/github/downloads/DentyTxR/DelayedPinkCandy/total.svg)]()

## Important notes!
- ### Yes this plugin comes with the ability to enable ping candy and set the %.

### How do I download this?
  - Go here and download the latest release, https://github.com/DentyTxR/DelayedPinkCandy/releases

### Default Config
```yml
is_enabled: true
debug: false
# The chance for a pink candy to be selected, 0-100 are valid numbers.
pink_candy_chance: 5
# The minimum delay in seconds before the explosion occurs after eating a pink candy.
min_delay: 2
# The maximum delay in seconds before the explosion occurs after eating a pink candy.
max_delay: 5
# Whether to toggle the hint when eating a pink candy.
toggle_hint_on_eat: true
# Hint message to display when eating a pink candy.
hint_on_eat: 'You feel a... delay'
# Duration for hint when eating a pink candy.
hint_on_eat_duration: 2
```
